## Six critères, six cibles mesurables

| Critère | Cible pour le site Alto |
|---------|-------------------------|
| Architecture | Cache + CDN, contenu séparé de la logique |
| Technologies | Stack connue, maintenue, documentée |
| Performance | LCP ≤ 2,5 s · INP ≤ 200 ms · CLS ≤ 0,1 |
| Sécurité | HTTPS, en-têtes, RGPD |
| Scalabilité | Projets ajoutés sans développeur |
| Coûts | ≤ 25 € par mois |

*Sources : [19] corewebvitals.io*
